- Gündem / Keşfet / Maçlar / Yorumcular
- Team detail rankings

## Next production gates
1. Replace initials with licensed/owned commentator images or safe remote assets.
2. Add an admin review UI for 65–94 confidence candidates.
3. Add explicit match_id to measurable predictions and automatic result evaluation.
4. Add push alerts only after a stable backend endpoint exists.
5. Confirm each source's robots/terms before automated production crawling.
6. Add privacy policy, terms, App Store metadata and analytics choice before TestFlight.
